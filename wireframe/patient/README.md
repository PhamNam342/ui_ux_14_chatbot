# Patient Wireframes

Low-fidelity desktop wireframes for the MedConsult patient role.

## Import into Figma

Drag each `.svg` file directly into a Figma Design canvas. SVG groups, text, rectangles,
circles, and lines remain editable after import.

## Included screens

1. Dashboard
2. Chatbot symptom consultation
3. Online consultation list
4. Doctor consultation chat
5. Appointment booking
6. Services and pricing
7. Medical records
8. Appointment calendar
9. Billing
10. Visit history
11. Account settings
12. Booking from chatbot assessment with prefilled clinic and specialty

Run `node wireframe/patient/generate-wireframes.mjs` from the repository root to rebuild
the SVG files after editing the generator.
